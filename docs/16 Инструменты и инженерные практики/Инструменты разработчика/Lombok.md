# Lombok

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* @Builder с @Singular для коллекций (своё имя метода для одного элемента) и @NonNull-проверка
* @Builder с @Singular, @NonNull
* @Value и @NonFinal для наследуемого неизменяемого класса
* @Delegate с excludes: композиция вместо наследования
* @Slf4j и @SneakyThrows
