# CI/CD

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Continuous Integration: автоматическая сборка и тесты при слиянии изменений
* Continuous Delivery и Continuous Deployment: различия
* Примерный workflow CI/CD: из каких стадий состоит пайплайн Java-сервиса (сборка, тесты, статанализ и security scan, сборка и публикация образа, деплой) и какими инструментами пользовались (GitLab CI, Jenkins, GitHub Actions)
* Стенды и релизный цикл: dev, test, stage, prod; версионирование артефактов и тегов образов
