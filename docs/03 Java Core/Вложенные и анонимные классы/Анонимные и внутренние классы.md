# Анонимные и внутренние классы

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Виды вложенных классов: static nested, inner, local, anonymous — различия и когда какой применять
* Внутренний (не static) класс и ссылка на экземпляр внешнего класса (Tree.this.name)
* Анонимный класс: определение (реализация интерфейса или абстрактного класса на месте)
* Мотивация: короткое тело, один экземпляр, использование в месте создания
* Объявление анонимного класса на примере интерфейса
* Анонимный класс-слушатель: захват effectively final переменной и доступ к полю внешнего класса через Outer.this
* Почему нестатический внутренний или анонимный класс может вызвать утечку памяти: неявная ссылка на внешний объект, double brace initialization
