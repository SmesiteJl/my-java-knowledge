# Рефлексия и класс Class

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Понятие рефлексии и её возможности
* Минусы рефлексии: производительность, ограничения безопасности, нарушение инкапсуляции
* Класс Class и способы получить его экземпляр: Class.forName, getClass(), .class
* getMethods() и getDeclaredMethods()
* Класс Method и его методы: getName, getReturnType, getParameterCount, invoke, setAccessible
* Доступ к приватным членам класса и вызов приватного метода через рефлексию
* Сигнатура метода в рефлексии: передача аргументов в invoke
* Создание объекта через рефлексию: getConstructor(...).newInstance(...)
* Понятие рефлексии: класс как значение переменной, работа с программой средствами самой программы
* Класс Class: хранит информацию о классе (имя, пакет, поля, методы)
* Три способа получить объект Class: obj.getClass(), MyClass.class, Class.forName (ClassNotFoundException)
* Создание экземпляра класса, имя которого введено с клавиатуры: Class.forName и newInstance
* Параметризация Class<T>, полиморфизм и позднее связывание; instanceof и нисходящее приведение
