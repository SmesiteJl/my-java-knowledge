# Аннотации: назначение и стандартные аннотации

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Аннотация как метаданные: конструкция, не влияющая на работу кода, но используемая другими программными средствами; что можно аннотировать — класс, метод, параметр, поле
* Стандартные аннотации: @Override, @Deprecated, @SuppressWarnings; зачем нужны аннотации на примере @Override — контроль переопределения при компиляции
* Создание собственной аннотации через @interface: элементы аннотации и значения по умолчанию (default, value)
* @Retention: SOURCE, CLASS, RUNTIME
* @Target и ElementType; несколько целей через массив
* Маркерный интерфейс или аннотация: что выбрать и почему
