# Классы-обёртки и автоупаковка

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Оболочки примитивных типов: зачем нужны — параметры generics и коллекций (List<int> нельзя), полезные методы (Integer.parseInt, Character.isDigit); null по умолчанию
* Абстрактный класс Number: наследники и методы byteValue, intValue, doubleValue и др.
* Автоматическая упаковка и распаковка (autoboxing и unboxing) в выражениях и присваиваниях: Integer i = 5 вместо явного конструктора, int j = i + 1
* Сравнение обёрток через == и пул (кеш) Integer: объекты без new берутся из пула, диапазон -128..127 (120 == 120 даёт true, 130 == 130 — false)
* Что выведет код: NPE при автораспаковке null, в том числе в тернарном операторе cond ? null : 0 в методе, возвращающем int
