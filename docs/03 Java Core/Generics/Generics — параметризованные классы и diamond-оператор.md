# Generics: параметризованные классы и diamond-оператор

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Generics: что это, с какой версии Java, пример без и с generics
* Цель использования generics: типобезопасность на этапе компиляции, читаемость
* Raw types (использование без параметров)
* Параметризация класса и объявление объекта параметризованного класса
* Diamond-оператор <> (Java 7)
* Generics: объявление класса или интерфейса с типом содержимого в качестве параметра
* Цель generics: проверка типов на этапе компиляции (CoolList<String>.add(123) не компилируется)
* Параметризация узла Elem<T> и списка CoolList<T>; вложенная параметризация CoolList<CoolList<Integer>>
* Объявление экземпляра параметризованного класса и diamond-оператор <> (с Java 7)
* Параметр Object и запрет примитивов в качестве параметра типа
