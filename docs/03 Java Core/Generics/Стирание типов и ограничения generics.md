# Стирание типов и ограничения generics

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Стирание типов: generics существуют только на этапе компиляции и не попадают в байт-код; причина — обратная совместимость с кодом до Java 5
* Ограничения из-за стирания: нельзя new T() и new T[], instanceof с параметром, static-поле типа T, перегрузка по разным параметризациям, примитивы
* Ограничение параметра типа <T extends Number> и вызов методов Number (пример CoolNumberList.sum)
* Bridge-методы: зачем компилятор их генерирует при стирании типов
* Когда информация о generic-типе доступна в рантайме: сигнатуры полей и методов, super type token (TypeReference в Jackson)
