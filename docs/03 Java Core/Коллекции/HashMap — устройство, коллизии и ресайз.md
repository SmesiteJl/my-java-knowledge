# HashMap: устройство, коллизии и ресайз

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* HashMap: put, get, remove, size за O(1) в среднем; хэш-таблица, бакеты-списки, индекс hash & (n-1), equals при коллизии, деревья в бакетах с Java 8
* Зачем hash() смешивает старшие биты (h ^ h >>> 16) и почему ёмкость таблицы — степень двойки
* Сложность get и put в HashMap: O(1) в среднем, худший случай O(n) до Java 8 и O(log n) после; treeify: порог 8 элементов в бакете, обратно при 6, минимальная ёмкость таблицы 64, как дерево строится без Comparable
* Ресайз HashMap: начальная ёмкость 16, load factor 0.75, threshold, удвоение таблицы и перераспределение элементов; как выбрать начальную ёмкость под известное число элементов и сколько объектов создаётся при put
* Метод цепочек против открытой адресации: почему HashMap выбрал цепочки
* HashMap против Hashtable: синхронизация, null-ключи и null-значения, почему Hashtable устарел
* Лайвкодинг: реализовать упрощённую HashMap с обработкой коллизий и ресайзом
