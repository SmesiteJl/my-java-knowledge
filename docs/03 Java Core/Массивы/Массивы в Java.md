# Массивы в Java

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Массив: определение, необходимость (вход для обработки, размер задаётся при выполнении)
* Одномерный массив: объявление ссылки, выделение памяти через new, значения по умолчанию, индексы от 0 до n-1
* Инициализация массива: new int[]{...} и литерал {...}
* Как пройти по всем элементам массива: length и цикл for
* Цикл for each по массиву: только чтение; когда for можно заменить на for each и наоборот
* Многомерные массивы: объявление, принцип организации, обход вложенными циклами
* Ступенчатые (jagged) массивы
* Класс java.util.Arrays: toString, equals, sort, копирование
