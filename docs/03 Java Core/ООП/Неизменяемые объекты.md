# Неизменяемые объекты

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Чем полезны неизменяемые объекты: потокобезопасность без синхронизации, безопасные ключи HashMap, кеширование; их цена — лишние аллокации
* Какие классы JDK неизменяемы: String, обёртки, BigDecimal, LocalDate, List.of
* Как написать неизменяемый класс: final-класс, private final поля, без сеттеров, defensive copy мутабельных полей в конструкторе и геттерах; почему недостаточно сделать все поля final и зачем final-класс (наследник с переопределённым геттером)
* Lombok @Value и @With: «изменение» через новый объект; аналогия с LocalDate и String
