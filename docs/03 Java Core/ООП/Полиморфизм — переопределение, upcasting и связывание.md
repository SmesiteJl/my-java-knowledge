# Полиморфизм: переопределение, upcasting и связывание

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Переопределение методов: только в контексте наследования, полная идентичность заголовка; правила — ковариантный тип возврата, нельзя сузить доступ, нельзя добавить или расширить checked-исключения в throws
* Восходящее преобразование (upcasting) на примере Animal → Cat → Tiger: что меняется (набор доступных методов) и что нет (сам объект)
* Связывание: присоединение вызова метода к телу метода, пример с массивом Contract
* Раннее (статическое) и позднее (динамическое) связывание: перегрузка против переопределения; пример Insurance и CarInsurance — переопределённый premium() против статического category()
* Как компилятор выбирает перегрузку: точное совпадение, расширение, автоупаковка, varargs; неоднозначный вызов с null (println(null))
* Почему private, static и final методы связываются статически
* Что выведет код: вызов статического метода через null-ссылку и через ссылку на родителя, поле с тем же именем в наследнике (сокрытие, а не переопределение)
