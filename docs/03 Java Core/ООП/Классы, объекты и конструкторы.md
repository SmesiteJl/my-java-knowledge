# Классы, объекты и конструкторы

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Цель использования объектно-ориентированной парадигмы
* Принцип «Абстракция»
* Класс: определение, структура, члены класса (атрибуты и методы) с примерами, правила именования
* Объявление экземпляра класса: объявление ссылки и выделение памяти через new
* Конструктор: назначение, конструктор по умолчанию, значения полей по умолчанию
* Оператор this: разрешение конфликта имён параметров и полей, вызов другого конструктора this(...)
* Какими способами можно создать объект без new: рефлексия, clone, десериализация, фабричные методы
