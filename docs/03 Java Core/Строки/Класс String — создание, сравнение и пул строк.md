# Класс String: создание, сравнение и пул строк

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Строка как ссылочный тип; создание через литерал и через new String
* Сравнение строк: == (сравнение ссылок) и equals (сравнение содержимого)
* Пул строк и особенности хранения строковых констант: один объект на литерал, склейка констант при компиляции; где хранится String Pool (PermGen до Java 7, затем heap) и может ли он вызвать OutOfMemoryError
* Что делает String.intern(), когда его применять и чем опасен intern на пользовательском вводе
* Неизменяемость строки (immutable): почему String неизменяемый и final — пул строк, безопасность (подмена после проверки), кеширование hashCode, потокобезопасность; изменяемые StringBuilder и StringBuffer
* Почему String — удобный ключ HashMap: неизменяемость и закешированный hashCode
* Почему пароль лучше хранить в char[], а не в String
* Во что компилируется конкатенация через +: StringBuilder до Java 8, invokedynamic и StringConcatFactory с Java 9
* Compact Strings (Java 9): Latin-1 или UTF-16 и поле coder; String deduplication в G1
* substring() до Java 7u6: общий char[] и утечка памяти; почему реализацию поменяли
