# Optional и ссылки на методы

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Optional: назначение (null-safety, защита от NullPointerException), возвращается терминальными методами (findAny, average); работа с ним: ofNullable, get, orElse, map
* Optional: orElse против orElseGet, of против ofNullable, опасность get() без проверки; почему Optional не используют в полях, параметрах и коллекциях
* Оператор :: (method reference) и его отличие от лямбды: String::toUpperCase, System.out::println, ссылка на собственный статический метод (Solution::printer)
