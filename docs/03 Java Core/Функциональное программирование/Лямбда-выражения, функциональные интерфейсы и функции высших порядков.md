# Лямбда-выражения, функциональные интерфейсы и функции высших порядков

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Функции высших порядков: map, filter, reduce (примеры на Python)
* Анонимный класс как предшественник лямбды: почему функциональный стиль в Java реализован через анонимные классы — нет функций, методы не объекты
* Функциональный интерфейс: один абстрактный метод (default-методы и методы Object не считаются), поля-константы, аннотация @FunctionalInterface
* Лямбда-выражение (появление в Java 8): лямбда-оператор ->, синтаксис (параметры) -> {тело}; лямбда как реализация метода функционального интерфейса и как объект анонимного класса
* Expression lambdas и statement lambdas
* Замена анонимного Comparator лямбдой в Collections.sort
* Свой @FunctionalInterface и обобщённый метод, принимающий лямбду (Equalator, Consumer)
* Ссылки на методы и конструкторы (Elf::new) вместо анонимного класса Supplier
* Чем лямбда отличается от анонимного класса: значение this, invokedynamic и LambdaMetafactory вместо отдельного .class, capturing и non-capturing лямбды, захват effectively final переменных
