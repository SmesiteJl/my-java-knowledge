# Обработка исключений: try-catch-finally, throw, throws

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Ключевые слова обработки исключений: try, catch, throw, throws, finally
* Блок try-catch: правила работы, видимость переменных, вложенные try; несколько catch в корректной последовательности (сначала наследники, затем суперклассы) и multi-catch (с JDK 7)
* Использование и смысл finally: всегда ли он выполняется; что вернёт метод с return в try или catch и return в finally; исключение в finally «съедает» исходное
* try-with-resources: AutoCloseable против Closeable, порядок закрытия ресурсов, suppressed-исключения
* Оператор throw: генерация исключения и повторный выброс пойманного (throw e)
* Exception chaining: оборачивание исключения с сохранением cause, wrap or rethrow
* Мотивация throws: проброс исключения вызывающему коду
* Необработанные исключения: стандартный обработчик и чтение стека вызовов
* Почему нельзя глотать исключения пустым catch и как правильно логировать исключение со стек-трейсом
* Checked-исключения внутри лямбд и функциональных интерфейсов: почему не компилируется и как обойти
* Можно ли выбросить checked-исключение без throws: sneaky throw через generics, Lombok @SneakyThrows
* Сколько стоит создание исключения: заполнение стек-трейса, fillInStackTrace, почему исключениями не управляют потоком выполнения
