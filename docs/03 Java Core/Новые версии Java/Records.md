# Records

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Что такое record (Java 16): что генерируется автоматически, ограничения (неявно final, нет наследования, нет полей экземпляра), компактный конструктор для валидации
* Record как ключ HashMap и DTO: неглубокая неизменяемость при мутабельных компонентах (массивы, списки), почему record не подходит для JPA-сущности
