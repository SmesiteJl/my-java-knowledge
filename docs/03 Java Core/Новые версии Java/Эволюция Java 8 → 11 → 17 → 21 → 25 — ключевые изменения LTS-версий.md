# Эволюция Java 8 → 11 → 17 → 21 → 25: ключевые изменения LTS-версий

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Что нового в Java 8, 11, 17 и 21 (лямбды и стримы, var, текстовые блоки, switch-выражения, records, sealed, виртуальные потоки) и какие версии LTS; на какой версии вы писали
* Чем Java 21 отличается от Java 17: виртуальные потоки, pattern matching для switch, record patterns, sequenced collections
* Нововведения Java 24 и что из 22–24 вошло в LTS 25: безымянные переменные _, Stream Gatherers; что до сих пор в preview — structured concurrency
* JEP 491 (JDK 24): почему synchronized больше не закрепляет виртуальный поток на носителе и где пиннинг остался
* Что финально в Java 25 (LTS, сентябрь 2025): scoped values, flexible constructor bodies, compact source files и instance main, module imports, compact object headers
* Риски миграции с Java 8 на 17 или 21: модули и strong encapsulation (--add-opens), удаление Java EE-модулей и javax → jakarta, смена GC по умолчанию
