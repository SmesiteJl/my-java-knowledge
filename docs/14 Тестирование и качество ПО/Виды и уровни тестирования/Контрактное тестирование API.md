# Контрактное тестирование API

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Contract testing защищает от тихих поломок интерфейсов при эволюции сервисов
* Consumer-driven contracts: Pact и Spring Cloud Contract; чем контрактный тест отличается от интеграционного
* Полное покрытие контракта POST /appointments: ответы 201, 400, 401, 403, 404, 409 SLOT_TAKEN, 422 и идемпотентный повтор, который возвращает тот же результат
