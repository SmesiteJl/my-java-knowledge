# OpenAPI и Swagger

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* OpenAPI как контракт: описание эндпоинтов, статус-кодов, путей и моделей
* Генерация спецификации аннотациями через springdoc-openapi в Spring Boot
* Swagger UI: просмотр и проверка эндпоинтов, контракт для фронтенда; адреса springdoc по умолчанию — /swagger-ui.html и /v3/api-docs
* API First (contract-first): генерация кода из OpenAPI-спецификации (openapi-generator) против code-first с аннотациями — плюсы и минусы
