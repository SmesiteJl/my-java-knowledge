# Сравнение REST, GraphQL и gRPC

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* REST, GraphQL и gRPC рядом: ресурсы, один эндпоинт с выбором полей, вызов процедур по контракту; таблица gRPC против REST
* Чем REST хорош и почему остаётся основным
* Какие проблемы REST решают альтернативы: over-fetching и under-fetching на примере заказа
* Почему не сделать отдельный эндпоинт под каждый экран; что такое BFF
* REST, GraphQL или gRPC — что когда выбрать; почему не gRPC везде, почему не перейти на GraphQL везде и не GraphQL между микросервисами
* Можно ли совмещать GraphQL и gRPC
* Чем REST отличается от SOAP: WSDL и строгий контракт, XML-конверт, WS-Security; где SOAP ещё встречается (банки, госинтеграции)
