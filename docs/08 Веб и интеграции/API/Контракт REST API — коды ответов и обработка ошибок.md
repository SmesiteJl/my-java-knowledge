# Контракт REST API: коды ответов и обработка ошибок

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Контракт POST /appointments: тело (patientId, doctorId, slotId, idempotencyKey) и коды 201/400/401/403/404/409
* Контракт POST /orders: заголовки (Authorization, Idempotency-Key), тело с expectedTotal, ответ 201
* Бизнес-ошибка (409 Conflict) и техническая (500) — разные сигналы, их нельзя смешивать
* Коды 400/401/409/422/429/503 и что делает клиент в каждом случае: бизнес-отказы (409, 422) повторять бесполезно, сбой (503) — повторить с тем же ключом
* Единый формат ошибок API: RFC 7807 Problem Details (type, title, status, detail) и соглашения об ошибках между сервисами
