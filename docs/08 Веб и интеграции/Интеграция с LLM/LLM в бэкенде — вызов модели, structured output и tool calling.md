# LLM в бэкенде: вызов модели, structured output и tool calling

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Как вызвать модель из Java-сервиса: ChatClient и advisors в Spring AI, LangChain4j; что держать в своём коде, а что отдать фреймворку
* Structured output: как получить JSON по схеме и что делать, если модель вернула не то — валидация, повтор, fallback
* Tool calling: кто исполняет инструмент, как ограничить его права, когда нужно подтверждение человека
* Таймауты, 429 и лимиты, стоимость в токенах, кэширование, идемпотентность повторов при вызове LLM API
* Как тестировать недетерминированный ответ модели: эталонные наборы и проверка инвариантов вместо сравнения текста
