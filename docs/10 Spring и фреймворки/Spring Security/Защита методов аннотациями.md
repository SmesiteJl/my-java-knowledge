# Защита методов аннотациями

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* @EnableGlobalMethodSecurity и флаги prePostEnabled, jsr250Enabled, securedEnabled
* @PreAuthorize и @PostAuthorize, @RolesAllowed (JSR-250), @Secured: различия
* Ограничения доступа в конфигурации против аннотаций над эндпоинтами
* @PostAuthorize с returnObject: проверка, что документ принадлежит текущему пользователю
