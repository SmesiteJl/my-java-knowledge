# @ConfigurationProperties и метаданные для автокомплита

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Настройка бинов стартера через application.properties и application.yml
* @ConfigurationProperties(prefix) + @EnableConfigurationProperties: как класс свойств становится бином; зачем геттеры и сеттеры
* spring-boot-configuration-processor: annotation processor генерирует JSON-метаданные для автокомплита в IDE
* @ConditionalOnProperty: бин создаётся, только если свойство задано
