# IoC-контейнер: задачи, плюсы и минусы

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Что делает IoC-контейнер: сборка зависимостей, ленивое создание объектов, управление жизненным циклом бинов
* Использование контейнера по шагам: реализация контейнера, описание модулей (@Component, @Inject), загрузка компонентов из пакета
* Какие проблемы решает контейнер: автоматическое внедрение зависимостей, уменьшение связанности, scopes
* Какие сложности добавляет: скрытая логика, рефлексия и трудная отладка, расход ресурсов, медленные тесты
* Несколько реализаций одного интерфейса: ошибка внедрения и решения через @Qualifier и @Primary
* Циклические зависимости бинов: почему возникают; почему цикл через конструкторы падает с BeanCurrentlyInCreationException, а через поля и сеттеры разрешается (трёхуровневый кэш синглтонов: singletonObjects, earlySingletonObjects, singletonFactories); @Lazy и пересмотр дизайна
