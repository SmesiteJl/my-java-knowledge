# Ленивые бины: @Lazy, lazyInit и @Primary

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* @Lazy на бине и на точке инъекции (ленивый прокси вместо реального объекта)
* @ComponentScan(lazyInit = true): создаются только бины, которые реально запрошены
* @Primary при нескольких реализациях одного типа
