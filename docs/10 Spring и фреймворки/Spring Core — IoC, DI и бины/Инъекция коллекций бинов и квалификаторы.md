# Инъекция коллекций бинов и квалификаторы

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Инъекция List<Interface> со всеми реализациями
* Своя мета-аннотация @Treatment = @Component + @Qualifier + @Autowired с атрибутом
* Инъекция подмножества бинов: свой @InjectList (BPP из стартера) и квалификатор @Legacy для бинов из чужого модуля
* @Autowired Map<String, Dao>: ключ — имя бина; включение и выключение DAO на лету
* Свой @Qualifier с enum-атрибутом (@Db(DBType))
* @DBRepo(DBType) = @Qualifier + @Autowired + @Repository: выбор реализации репозитория по enum
* @Scheduled(fixedDelay) для периодических задач
