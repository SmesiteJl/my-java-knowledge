# Задачи на SQL (лайвкодинг)

* Лайвкодинг: найти дубликаты по полю или набору полей через GROUP BY … HAVING COUNT(*) > 1
* Лайвкодинг: имя клиента и общая сумма его заказов с фильтрами по активности и сумме > 0 (JOIN + GROUP BY + HAVING)
* Лайвкодинг: найти вторую (N-ю) по величине зарплату и вернуть NULL, если её нет
* Лайвкодинг: сотрудники с максимальной зарплатой в каждом отделе / топ-N в каждой группе (оконная функция или коррелированный подзапрос)
* Лайвкодинг: нарастающий итог продаж по месяцам с разбивкой по группе
* Лайвкодинг: удалить полные дубликаты строк, оставив по одной, без создания новой таблицы (ROW_NUMBER, ctid)
