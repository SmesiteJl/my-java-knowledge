# Индексы

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Назначение индексов; индекс как вспомогательная структура; роль в ограничениях целостности; первичный ключ создаёт индекс
* Виды индексов: основные по механизму — B-tree и hash; в PostgreSQL также GIN, GiST, BRIN, SP-GiST — для каких данных и запросов каждый (jsonb, полнотекст, массивы, геоданные, временные ряды)
* Почему для индекса используют B-дерево, а не бинарное или красно-чёрное дерево, как в HashMap
* Кластерный и некластерный индекс; как это устроено в PostgreSQL (heap, CLUSTER) и в InnoDB
* Покрывающий индекс: плюсы и минусы
* Составные индексы, индексы по выражениям, частичные индексы — когда имеют смысл; для составного — правило левого префикса, порядок колонок, нужны ли отдельные индексы по A и B при индексе (A, B)
* Селективность и кардинальность: есть ли смысл индексировать колонку с малым числом значений (boolean, статус)
* Когда индекс не используется: функция над колонкой, LIKE '%…', приведение типов, OR, низкая селективность, маленькая таблица, устаревшая статистика
* Минусы индексов: замедление записи, место на диске, bloat; почему нельзя проиндексировать все колонки и их комбинации
* Индекс по «тяжёлым» колонкам (JSON с логами): GIN по jsonb, индекс по выражению, TOAST
