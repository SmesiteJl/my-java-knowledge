# Реляционная модель, типы столбцов и ключи

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Реляционная модель: таблица = отношение, строка = кортеж, столбец = атрибут; отношение по Кодду — подмножество декартова произведения доменов, степень отношения
* Типы данных ANSI SQL: строковые, бинарные, числовые, логический, дата и время; не все поддерживаются конкретной СУБД
* CHAR, VARCHAR, NCHAR — различия; хранение строк в MySQL (CHAR, VARCHAR, TEXT/BLOB, ENUM, SET)
* NUMERIC/DECIMAL, BOOLEAN, TIMESTAMP, TEXT, BLOB
* DATETIME против TIMESTAMP; timestamp и timestamptz в PostgreSQL — как хранить время
* Первичный ключ: уникальный набор полей; простой, составной, потенциальный и альтернативный ключи; естественный ключ против суррогатного целочисленного ID; почему PK — не порядковый номер
* Внешний ключ: ссылка на первичный ключ другой таблицы
