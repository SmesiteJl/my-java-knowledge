# Конкурентное резервирование: условный UPDATE, SELECT FOR UPDATE, оптимистическая блокировка

* Сортировка позиций по sku_id против взаимоблокировок
* READ COMMITTED в PostgreSQL: перепроверка WHERE после ожидания блокировки строки
