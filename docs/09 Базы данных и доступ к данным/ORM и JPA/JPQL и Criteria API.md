# JPQL и Criteria API

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* JPQL: запросы в терминах сущностей и полей, отличия от SQL, навигация по связям без явного JOIN
* Ограничения JPQL и native-запросы через createNativeQuery
* Criteria API и CriteriaBuilder: динамические типобезопасные запросы, метамодель
* Плюсы и минусы JPQL и Criteria API, когда что выбирать
* EntityManager как Data Mapper: составляет запросы, ведёт учёт объектов в пуле, маппит результаты на сущности
* Именованные параметры в JPQL (:age и setParameter)
