# Нормальные формы

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Одна таблица или несколько: проблемы хранения повторяющихся данных (все «улицы Ленина» в одной таблице)
* 1НФ: атомарные значения в ячейках, нет дубликатов строк
* 2НФ: каждый неключевой атрибут зависит от всего потенциального ключа, а не от его части (пример AB → C, A → D)
* 3НФ: нет транзитивных зависимостей неключевых атрибутов от ключа
* БКНФ (усиленная 3НФ): для любой зависимости X → Y X — потенциальный ключ
* 4НФ: многозначные зависимости (пример студент — предмет — преподаватель)
* 5НФ: зависимости соединения определяются только потенциальными ключами
* ДКНФ (Fagin, 1981) и 6НФ: определения
* Денормализация: когда оправдана и чем за неё платим
