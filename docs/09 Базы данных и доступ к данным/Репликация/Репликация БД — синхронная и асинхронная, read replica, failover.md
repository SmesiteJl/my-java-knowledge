# Репликация БД: синхронная и асинхронная, read replica, failover

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Что такое репликация БД
* Типы по способу синхронизации: транзакционная, снимками, слиянием, одноранговая, двунаправленная
* Типы по способу передачи: синхронная, асинхронная, полусинхронная; физическая и логическая репликация
* Типы по архитектуре: с одним лидером, с несколькими лидерами, без лидера
* Зачем нужна репликация (ускорение доступа, бэкап) и варианты синхронности копий: всегда одинаковы или копирование по условию
* Синхронная реплика в другой зоне ради RPO = 0 и асинхронная read replica для каталога
* Автоматическое переключение ≤ 60 с; запасной путь чтения каталога с синхронной реплики
* PostgreSQL primary, синхронный standby и асинхронная read replica в разных зонах; переключение за 30–60 с без потерь
* Запись масштабируется вертикально, чтение — через реплику; при отказе реплики чтение со standby
