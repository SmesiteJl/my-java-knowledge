# My Java Knowledge

База знаний по Java backend и программированию в целом: от основ языка до тем,
которые спрашивают на собеседованиях уровня middle.

Здесь собрано то, что я прохожу сам, готовясь к собеседованиям: Java Core и JVM, многопоточность,
Spring, базы данных, сети, операционные системы, архитектура, распределённые системы и информационная
безопасность. Каждая тема — рассказ: от того, как всё устроено по умолчанию, через документацию и исходники
к тому, где на этом спотыкаются, — и по ходу он отвечает на вопросы, которые задают на собеседованиях.

## Как пользоваться

- Разделы сверху — большие тематики, внутри — области и темы.
- В конце темы — вопросы для самопроверки: список того, что спрашивают на собеседованиях и что разобрано в тексте.
- Цифры в тексте — сноски с подробностями, которые сбили бы рассказ. Источники — ссылками прямо в тексте и списком в конце.
- Поиск по всей базе — значок лупы в шапке.
