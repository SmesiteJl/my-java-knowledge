# JWT

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Что такое JWT и как он используется для передачи данных между сервисами: сервер аутентификации выдаёт JWT, клиент передаёт его в вызовах API, сервер приложения проверяет токен
* Структура JWT: Header, Payload, Signature, кодирование base64
* Подпись JWT приватным ключом и проверка публичным; симметричный HMAC (HS256) против асимметричной RSA/ECDSA (RS256, ES256) — что выбрать, если токен проверяют несколько сервисов
* Сессии на сервере против JWT (stateful против stateless): масштабирование на несколько инстансов, отзыв, размер, общее хранилище сессий (Redis, Spring Session)
* Зачем нужна пара access- и refresh-токенов и что даёт ротация refresh-токена при каждом обновлении
* Как отозвать JWT до истечения срока: короткий TTL access-токена, отзыв refresh-токена, чёрный список по jti
* Где хранить токены в браузере: localStorage против HttpOnly-cookie — риски XSS и CSRF
