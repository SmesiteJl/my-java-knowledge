# OAuth, OpenID, SSO, SAML

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Сквозная аутентификация (SSO)
* OAuth (авторизация), OpenID (аутентификация), SAML (описание прав): различия; OpenID Connect поверх OAuth 2.0 — ID token против access token, чем аутентификация отличается от делегирования доступа
* Поток «войти через сервис»: редирект с токеном, запрос данных пользователя со стороны сервера
* Какими данными обмениваются при сквозной авторизации: ключ подписи приложения, токен авторизации, токен доступа, токен обновления
* Роли OAuth 2.0 и типы грантов: authorization code (с PKCE), client credentials для межсервисных вызовов; почему implicit и password считаются устаревшими
