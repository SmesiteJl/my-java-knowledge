# Доступ к чужим объектам: проверка владельца ресурса

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* AC FR-12: запрос чужого заказа возвращает 404
* NFR-05: все запросы, кроме каталога, требуют токен; вебхуки проверяются по подписи; 100% действий диспетчера в аудите (тест SEC-01)
* Сценарий QS-06: чужой заказ под своим токеном → 404 и запись в лог с correlation-id
* Проверка перебором чужих идентификаторов (SEC-01)
* Риск R-03 «пользователь видит чужие ПД»: проверка роли в BFF и владельца записи в сервисе, аудит обращений, тесты с чужим appointmentId (OWASP API Security Top 10)
* Contingency: блокировка учётной записи, отключение маршрута, выборка затронутых записей по аудиту
