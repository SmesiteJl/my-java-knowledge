# SQL-инъекции

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Что такое SQL-инъекция и как она проводится через параметры формы: классический сценарий подстановки параметра в SQL, разбор примера «Роберт'); DROP TABLE students; --»
* Почему Statement со склейкой строк уязвим
* SQL-инъекция как склейка запроса с вводом и защита: фильтрация входных параметров и удаление из них SQL-кода, экранирование, параметризованные запросы (PreparedStatement), валидация, минимальные права учётной записи БД, WAF; почему вычищать SQL-код из параметров — плохой способ
* Какие символы экранировать, если нет PreparedStatement (вопрос с экзамена)
* SQL-инъекции в JPA и Hibernate: конкатенация в JPQL/HQL и nativeQuery, динамический ORDER BY, который нельзя параметризовать (белый список столбцов)
* Почему символы % и _ в LIKE-запросах через ORM нужно экранировать самостоятельно
* Инъекции как следствие формата данных: XXE в XML, формулы в CSV
