# CSRF

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Механизм CSRF-атаки (подделка межсайтового запроса): этапы и роль сессионных cookie
* Почему GET-эндпоинты с побочными эффектами опасны и почему переход на POST не защищает полностью
* Методы защиты: история запросов, повторное подтверждение, подпись запросов, CSRF-токены, cookie с атрибутом SameSite
* Алгоритм CSRF-токена: генерация, хранение в сессии, скрытое поле формы, сравнение, новый токен на новое действие
* Проблемы CSRF-токенов: несколько вкладок, истечение сессии, для каких действий их генерировать
* Нужна ли CSRF-защита REST API со stateless JWT в заголовке Authorization, почему её отключают в Spring Security и когда она обязательна (аутентификация по cookie)
