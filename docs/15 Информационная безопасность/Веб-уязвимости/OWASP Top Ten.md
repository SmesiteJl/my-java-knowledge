# OWASP Top Ten

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Что такое OWASP и рейтинг Top Ten
* Broken Access Control, Cryptographic Failures, Injection, Insecure Design, Security Misconfiguration
* Vulnerable and Outdated Components, Identification and Authentication Failures, Software and Data Integrity Failures
* Security Logging and Monitoring Failures, Server-Side Request Forgery (SSRF)
* SSRF: как злоумышленник заставляет сервер обратиться к внутреннему адресу (localhost, метаданные облака) и как защищаться
* Что изменилось в OWASP Top 10:2025: A03 Software Supply Chain Failures, A10 Mishandling of Exceptional Conditions, SSRF внутри A01
* Классификация уязвимостей со слайда лектора: SQL-инъекции, XSS, CSRF, открытые доступы и логические ошибки, уязвимости вспомогательного ПО, проблемы сетевой архитектуры
* Открытый доступ к админке без фильтра и другие логические ошибки
* Path traversal через «..» в пути к файлу
* Уязвимости вспомогательного ПО: веб-сервер, интерпретатор ЯП, сервер СУБД
* OWASP Top 10 применительно к Spring-приложению: что закрывают Spring Security и Spring Boot по умолчанию, а что остаётся на разработчике (проверка доступа к объектам, валидация, зависимости)
