# Безопасность LLM-интеграций: prompt injection и утечки данных

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Prompt injection, прямой и косвенный: через документы, письма, сообщения пользователей — почему ввод для модели недоверенный
* Почему у модели не должно быть прав, которых нет у пользователя, и где нужен человек в цикле
* Как не отправить в модель персональные данные и секреты: маскирование, что писать в логи
* Что из OWASP Top 10 для LLM касается бэкенда: небезопасная обработка вывода, избыточные полномочия, неограниченное потребление
