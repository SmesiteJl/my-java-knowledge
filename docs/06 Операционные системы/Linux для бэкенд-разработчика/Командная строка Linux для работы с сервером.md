# Командная строка Linux для работы с сервером

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Где в Linux хранится информация о процессах (/proc/<pid>) и как смотреть процессы: ps aux, pstree, top
* systemd и systemctl: как запустить Java-приложение как сервис (unit-файл, автоперезапуск) и смотреть его логи через journalctl -u
* Работа с логами на сервере: tail -f, less, grep с флагами (-i, -r, -A/-B, -v), head, wc и их комбинация через конвейер
