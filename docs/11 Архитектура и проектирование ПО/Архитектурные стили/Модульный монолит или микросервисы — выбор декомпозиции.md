# Модульный монолит или микросервисы: выбор декомпозиции

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Варианты декомпозиции: микросервис на каждую область, модульный монолит + отдельные каталог и уведомления, один монолит
* Главный довод: одна транзакция «заказ + резерв» вместо саги между базами
* Минусы модульного монолита: совместный релиз, общая БД, границы модулей держатся на ревью
* Правила между модулями: пишет только в свои таблицы, вызовы через интерфейсы, результаты — событиями, внешние вызовы вне транзакции
