# Алертинг и runbook

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Алерты, привязанные к SLO: баланс между тишиной и истерикой
* Примеры алертов MediBook: рост p95 поиска, 5xx на записи, рост DLQ, недоступность Auth, нет audit events, скачок конфликтов
* Runbook: симптомы, причины, диагностика, безопасные действия, критерии эскалации; алерт без runbook — тревога без плана
* Поток: метрика или событие → порог → алерт → runbook → диагностика → эскалация или решение
* Нет превышения порога — нет алерта
* Пять алертов: условие, привязка к SLO, кого будить, первое действие
* Обоснование порогов и снижение шума: ночью не будить, CPU и перезапуски — только на дашборды
* Runbook RB-02: симптомы, причины, диагностика (kubectl, rabbitmqctl), безопасные и запрещённые действия, эскалация
