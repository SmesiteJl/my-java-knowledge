# Одиночка (Singleton)

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Суть Singleton: класс с единственным экземпляром (столица, база данных, главный босс) и глобальная точка доступа, метод getInstance()
* Тип (порождающий) и устройство: приватный конструктор, статическое поле instance, ленивое создание в getInstance(); пример EvilBossSingleton — ленивое создание при первом обращении вместо проверок null в бизнес-логике
* Где применять: подключение к БД, конфигурация; синглтоны DAO и сервисов в примере веб-приложения
* Чем паттерн Singleton отличается от singleton-бина Spring и почему DI предпочтительнее getInstance()
