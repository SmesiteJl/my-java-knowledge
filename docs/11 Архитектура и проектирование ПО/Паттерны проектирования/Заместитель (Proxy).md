# Заместитель (Proxy)

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Идея паттерна Proxy: клиент получает заместителя реального объекта (RealSubject) с контролируемым доступом, который может обратиться к нему, а может и нет; аналогия с прокси-сервером, фильтрующим доступ к сайтам
* Структура паттерна: общий интерфейс, Proxy хранит realService и проверяет доступ перед делегированием
* Как Java подставляет прокси вместо оригинала: полиморфизм через интерфейсы или наследование
* Прокси в ORM при ленивой загрузке; em.getReference() против em.find()
* Прокси в Spring: поле с @Lazy внедряется при первом использовании
* Как распознать прокси в рантайме: классы $HibernateProxy$ у сущностей и $$EnhancerBySpringCGLIB$$ у бинов
* Чем Proxy отличается от Decorator; виды прокси (виртуальный, защищающий, удалённый, кэширующий) с примерами из Java и Spring
