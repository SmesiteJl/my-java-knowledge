# Наблюдатель (Observer)

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Суть паттерна Listener: механизм подписки на события другого объекта
* Пример Button + EventListener.onEvent
* Где применяется: GUI, системы очередей сообщений
* Event-Driven Design: независимые компоненты общаются через события
* Брокер событий: производители публикуют события, потребители подписаны на нужные типы
* Блог-движок рассылает событие о новом посте подписчикам; ошибка одного подписчика не ломает остальных
