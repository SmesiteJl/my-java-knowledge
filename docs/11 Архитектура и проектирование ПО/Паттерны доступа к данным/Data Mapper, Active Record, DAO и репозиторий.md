# Data Mapper, Active Record, DAO и репозиторий

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Data Mapper: отделение объектов предметной области от БД; пример UserMapper; где применяется (Hibernate/JPA)
* Active Record: объект сам умеет save/findById; когда уместен (простые CRUD, Rails)
* DAO и репозиторий как варианты Data Mapper; пример SectionDAO на JdbcTemplate
