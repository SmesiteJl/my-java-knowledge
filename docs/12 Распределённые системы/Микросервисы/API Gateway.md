# API Gateway

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* API Gateway как единая точка входа, паттерн reverse proxy
* Функции шлюза: маршрутизация, агрегация ответов, безопасность, rate limiting, кэширование, преобразование протоколов, мониторинг
* Когда нужен API Gateway: много сервисов, централизация безопасности, логирования и ограничений, сокрытие сложности от клиента
* Преобразование протоколов в шлюзе: REST и JSON, SOAP, XML поверх HTTP и JMS
* API Gateway (Spring Cloud Gateway): проверка токена, ограничение частоты, выдача correlation-id, маршрутизация
* Вебхуки PSP через тот же Gateway с проверкой подписи вместо пользовательского токена
* Spring Cloud Gateway: маршруты по Path на lb://service, discovery locator
* Агрегация Swagger всех сервисов через gateway
