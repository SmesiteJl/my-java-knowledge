# Быстрая сортировка (QuickSort)

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Алгоритм быстрой сортировки: выбор опорного элемента, разбиение, рекурсия
* Выбор опорного элемента: медиана трёх и влияние на худший случай
* Лучший и средний случай O(n log n): вывод через глубину рекурсии
* Худший случай O(n²): когда возникает
* Память: O(1) дополнительно в теории и до O(n) на стек рекурсии
* Рекурсивная реализация с опорным элементом посередине
* Идея быстрой сортировки: опорный элемент и два указателя
* Оценка времени в среднем и лучшем случае O(n log n)
* Худший случай O(n²)
* Память: глубина рекурсии O(log n)…O(n)
