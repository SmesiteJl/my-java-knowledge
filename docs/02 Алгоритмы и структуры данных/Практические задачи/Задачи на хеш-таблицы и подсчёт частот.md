# Задачи на хеш-таблицы и подсчёт частот

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Лайвкодинг: найти дубликаты в массиве или списке за O(n) через HashSet
* Лайвкодинг: пересечение двух массивов или строк (сколько символов одной строки встречается в другой) через HashSet за O(n + m)
* Лайвкодинг: являются ли две строки анаграммами — подсчёт частот символов в массиве или HashMap; почему сравнение через Set неверно
* Лайвкодинг: первый неповторяющийся символ строки за O(n) — два прохода со счётчиком
* Лайвкодинг: сгруппировать слова-анаграммы, ключ — отсортированное слово или вектор частот
* Лайвкодинг: two sum за O(n) через HashMap «значение → индекс» вместо перебора пар за O(n²)
* Лайвкодинг: число подмассивов с суммой K за O(n) — префиксные суммы плюс HashMap
