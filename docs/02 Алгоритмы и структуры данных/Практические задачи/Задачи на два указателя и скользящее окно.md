# Задачи на два указателя и скользящее окно

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Лайвкодинг: развернуть строку и проверить палиндром двумя указателями без готовых методов вроде StringBuilder.reverse
* Лайвкодинг: преобразование массива на месте двумя указателями — удалить повторы из отсортированного массива, сдвинуть нули в конец
* Лайвкодинг: отличаются ли две строки ровно на одну правку (вставка, удаление или замена символа) за O(n)
* Лайвкодинг: максимальная длина серии единиц в бинарном массиве за один проход и O(1) памяти
* Лайвкодинг: длина самой длинной подстроки без повторяющихся символов — скользящее окно переменной длины
