* Лайвкодинг: развернуть односвязный список итеративно (O(n) времени, O(1) памяти) и рекурсивно
* Лайвкодинг: слить два отсортированных связных списка в один, переставляя ссылки без создания новых узлов
* Лайвкодинг: быстрый и медленный указатели — найти цикл в списке (алгоритм Флойда) и середину списка за один проход
