# TCP и UDP

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* UDP: передача без соединения, датаграммы, отсутствие гарантий доставки и порядка
* Заголовок UDP (8 байт): порты, длина, контрольная сумма
* TCP: установление соединения, сегменты, гарантия доставки и порядка, управление потоком
* Поля заголовка TCP: порты, порядковый номер, номер подтверждения, флаги, окно, контрольная сумма
* Когда выбрать TCP, а когда UDP; в Java для TCP — Socket, для UDP — Datagram
* Функции транспортного уровня: мультиплексирование по портам, надёжность доставки
* TCP: установление соединения, оконная передача, подтверждение приёма, перезапрос потерянных данных
* UDP: датаграммы без установления соединения, отсутствие гарантий доставки и порядка
