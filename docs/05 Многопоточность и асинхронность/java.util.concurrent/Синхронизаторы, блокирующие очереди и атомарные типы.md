# Синхронизаторы, блокирующие очереди и атомарные типы

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Состав пакета java.util.concurrent: синхронизаторы, исполнители, коллекции
* Semaphore: acquire и release, ограничение числа потоков
* CountDownLatch: ожидание N событий через await
* CyclicBarrier: ожидание, пока N потоков не вызовут await
* BlockingQueue и BlockingDeque: блокировка при чтении из пустой и записи в заполненную очередь
* Атомарные типы AtomicInteger, AtomicLong, AtomicIntegerArray и compareAndSet: как работает CAS и почему атомики обходятся без блокировок; ABA-проблема и AtomicStampedReference; volatile против Atomic*
* LongAdder против AtomicLong при высокой конкуренции
* Лайвкодинг: неблокирующий стек на AtomicReference и CAS
