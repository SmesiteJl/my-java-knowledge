# Потокобезопасные коллекции

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* ConcurrentModificationException при изменении коллекции во время итерации
* Collections.synchronizedList и почему он не спасает при итерации с изменением
* CopyOnWriteArrayList: чтение и изменение во время обхода
* Что будет с HashMap при конкурентной записи: потеря записей, зацикливание при ресайзе в Java 7
* ConcurrentHashMap вместо HashMap: чем они принципиально отличаются помимо потокобезопасности — null в ключах и значениях, fail-fast и weakly consistent итераторы, атомарные compute/putIfAbsent, масштабирование под нагрузкой
* ConcurrentHashMap против Collections.synchronizedMap и Hashtable
* Как устроен ConcurrentHashMap в Java 8: CAS для пустого бакета, synchronized на голове бакета, чтение без блокировок; чем отличался вариант с сегментами в Java 7
* Почему get и затем put в ConcurrentHashMap не атомарны и в чём подвох computeIfAbsent: долгая функция под блокировкой бакета, рекурсивное изменение map
* ConcurrentSkipListMap, ConcurrentLinkedQueue и выбор BlockingQueue: ArrayBlockingQueue, LinkedBlockingQueue, SynchronousQueue
