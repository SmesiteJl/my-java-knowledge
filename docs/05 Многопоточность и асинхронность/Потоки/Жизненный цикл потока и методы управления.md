# Жизненный цикл потока и методы управления

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Жизненный цикл потока: состояния NEW, RUNNABLE, BLOCKED, WAITING, TIMED_WAITING, TERMINATED и переходы между ними
* Метод sleep() и состояние TIMED_WAITING
* Метод join(): ожидание завершения другого потока
* Методы wait(), notify(), notifyAll()
* Метод interrupt() и InterruptedException: как корректно остановить поток — флаг прерывания, interrupted() против isInterrupted(), почему Thread.stop() запрещён, что делать с InterruptedException
* Daemon-поток не удерживает JVM после завершения main
* Что происходит при исключении в потоке: UncaughtExceptionHandler; как получить исключение из задачи пула (execute против submit, ExecutionException)
* Лайвкодинг: запустить потоки T1, T2, T3 строго по очереди или печатать числа поочерёдно из двух потоков
