# Java Memory Model: happens-before, видимость, переупорядочивание

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Что такое Java Memory Model и какие проблемы она решает: видимость, атомарность, переупорядочивание инструкций
* Отношение happens-before: основные правила (порядок в потоке, монитор, volatile, start и join, транзитивность)
* Как volatile запрещает переупорядочивание: барьеры памяти, as-if-serial семантика
* Какие операции атомарны без синхронизации: запись long и double без volatile, присваивание ссылок
* Гарантии JMM для final-полей и безопасная публикация объекта (safe publication)
* Потокобезопасный Singleton: double-checked locking и зачем там volatile, holder-идиома, enum
