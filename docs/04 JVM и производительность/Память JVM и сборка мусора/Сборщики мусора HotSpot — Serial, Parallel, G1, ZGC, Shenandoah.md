# Сборщики мусора HotSpot: Serial, Parallel, G1, ZGC, Shenandoah

> [!NOTE] Тема в работе
> Статьи по этой теме пока нет. Вот вопросы, на которые она ответит.

* Какие сборщики есть в HotSpot, чем они отличаются и какой используется по умолчанию (G1 с Java 9)
* Как устроен G1: регионы, young- и mixed-сборки, remembered set, целевая пауза MaxGCPauseMillis, humongous-объекты
* ZGC и Shenandoah: конкурентное уплотнение, цветные указатели и барьеры чтения, паузы меньше миллисекунды
* G1 или ZGC: как выбрать сборщик под задачу — пропускная способность, задержки, размер кучи
