# My Java Knowledge

A knowledge base for Java backend development and programming in general, from the basics of the language to the topics that come up in mid-level interviews.

Here’s what I’m working through as I prepare for interviews: Java Core and the JVM, concurrency, Spring, databases, networks, operating systems, architecture, distributed systems, and information security. Each article starts with what happens by default. Then we look at the docs and the source code, see where things trip us up, and answer interview questions along the way.

## How to use the site

- Start with a subject in the navigation, or use the search icon in the header.
- The questions at the end of an article let you check what you can explain without looking back.
- Footnotes go into details that would interrupt the article. Sources are linked where we use them and listed at the end.
