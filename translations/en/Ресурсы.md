# Resources

Books, repositories, and channels I use to prep for interviews.

## Books and textbooks

* [Hello Algo](https://www.hello-algo.com/ru/) — the Russian edition of a great Chinese book on algorithms. It shows you how they work with animations and code examples in a bunch of languages. If I'd known about it back when I was doing competitive programming in school, I'd have been a hundred times better.

## Repositories

* [iluwatar/java-design-patterns](https://github.com/iluwatar/java-design-patterns) — Java implementations of all the design patterns.
* [spring-projects/spring-boot](https://github.com/spring-projects/spring-boot) — an obvious one, but still: the Spring Boot source code. I recommend it to everyone.
* [doocs/advanced-java](https://github.com/doocs/advanced-java) — a big collection of interview questions and answers for mid-level and senior Java backend developers, mostly in Chinese. The title translates roughly to “A Complete Primer on Advanced Topics for Java Engineers at Internet Companies.” Most of the material comes from 中华石杉 (Zhonghua Shishan); the Doocs community organized it into a guide.
* [TheAlgorithms/Java](https://github.com/TheAlgorithms/Java) — Java implementations of just about every algorithm.
* [codecrafters-io/build-your-own-x](https://github.com/codecrafters-io/build-your-own-x) — a straightforward guide to building your own version of pretty much anything. Not many Java examples, though.

## Roadmaps

* [roadmap.sh/java](https://roadmap.sh/java) — a bare-bones roadmap for Java developers. I'd say it more than covers what a junior developer needs, but it doesn't quite get you to mid-level.
* [My interview prep roadmap](Роадмап.html) — the plan I follow myself: 18 weeks starting October 26, 2026. The phases are ordered by how often topics come up in real interviews, with live coding, SQL, review, and a project to experiment on alongside them. Topics that already have an article in the knowledge base are clickable.

## YouTube

* [Vlad Mishustin](https://www.youtube.com/@fakng-engineer) — a Java developer who explains seemingly complicated things in plain Russian, with graphics and diagrams.
    * [How a web app works](https://www.youtube.com/watch?v=8j29aAbtYWo) — a clear, beginner-friendly video in Russian on how the pieces of a web app fit together.
* [JUG Ru](https://www.youtube.com/@JUGru) — conference talks by different speakers, mostly in Russian. It's a good place to find recent talks on all kinds of topics, as well as the classic *Spring Ripper* (“Spring-потрошитель”).
