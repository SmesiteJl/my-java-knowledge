# My Java Knowledge

База знаний по Java backend и программированию в целом: от основ языка до тем, которые спрашивают
на собеседованиях уровня middle. Собираю её сам, пока прохожу эти темы.

**Сайт:** [Русский](https://smesitejl.github.io/my-java-knowledge/ru/) ·
[English](https://smesitejl.github.io/my-java-knowledge/en/)

## Что внутри

Java Core и JVM, многопоточность, Spring, базы данных, сети, операционные системы, архитектура,
распределённые системы, информационная безопасность. Каждая тема — рассказ: как всё устроено по умолчанию,
что говорит документация, как сделать правильно и где на этом спотыкаются. В конце темы — вопросы
с собеседований, которые она закрывает.

База растёт по мере того, как я прохожу темы: здесь только то, что уже написано.

## Как собрать локально

Из корня этого репозитория, с Python 3.11 или новее:

```bash
python3 -m pip install -r requirements.txt
python3 build_languages.py --serve
```

Предпросмотр откроется по адресу http://127.0.0.1:8000/. Без `--serve` команда только собирает `site/` —
тот же каталог публикуется на GitHub Pages.

На главной `/ru/` выберите **English** в шапке: откроется `/en/`, с английским меню и собственным поиском.
На русской статье без перевода рядом с **English** будет «нет перевода» вместо ссылки. Для проверки старого
адреса откройте `/Роадмап.html?from=old#P0`: он перенаправит на `/ru/Роадмап.html?from=old#P0`.
Перенаправление сохраняет запрос и фрагмент с включённым JavaScript; без него остаётся обычная ссылка.

## Как добавить язык или перевод

В мастерской добавьте запись в `publish/languages.json` (в этой выгрузке — `languages.json`). Ключ — код
языка темы Zensical и первый сегмент адреса, например `zh` для `/zh/`. В записи:

- `name` — название языка в переключателе на самом языке; `selector` — подпись переключателя;
  `unavailable` — подпись отсутствующего перевода на языке открытой страницы.
- `home` — подпись главной в меню для нового языка; для `ru` меню приходит из `zensical.toml`.
- `description` — необязательное описание сайта на этом языке.
- `palette_labels` — необязательные три подписи переключателя темы в порядке настроек `zensical.toml`;
  вне `ru` по умолчанию используются английские подписи.
- `extra_css` — необязательный список путей к CSS нового языка относительно корня его исходников.
  Эти стили подключаются после общей таблицы из `docs/`; используйте отдельные имена файлов.

В `translations/<код>/` положите `index.md` и готовые переводы. Относительные **имена файлов и каталогов**
сохраняйте как в русском `docs/`: именно они связывают одну статью с другой. Заголовок в Markdown, наоборот,
переводите — из него берётся название пункта меню. Изображения и другие вложенные ресурсы кладите рядом со
страницами на соответствующих относительных путях. Автономные HTML-страницы пишите как полный документ
с `<head>` и `<body>`; используйте в них относительные ссылки на итоговые адреса страниц.

Если перевода ещё нет, не создавайте для него пустой файл и не ставьте локальную ссылку на него. В тексте
можно оставить название без ссылки либо явно сослаться на опубликованный русский оригинал с пометкой языка.
