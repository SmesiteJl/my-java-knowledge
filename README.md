# My Java Knowledge

База знаний по Java backend и программированию в целом: от основ языка до тем, которые спрашивают
на собеседованиях уровня middle. Собираю её сам, пока прохожу эти темы.

**Сайт:** https://smesitejl.github.io/my-java-knowledge/

## Что внутри

Java Core и JVM, многопоточность, Spring, базы данных, сети, операционные системы, архитектура,
распределённые системы, информационная безопасность. Каждая тема — рассказ: как всё устроено по умолчанию,
что говорит документация, как сделать правильно и где на этом спотыкаются. В конце темы — вопросы
с собеседований, которые она закрывает.

База растёт по мере того, как я прохожу темы: здесь только то, что уже написано.

## Как собрать локально

```bash
pip install -r requirements.txt
zensical serve
```

Сайт откроется на http://127.0.0.1:8000.
